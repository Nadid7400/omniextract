REST API Reference

          Integrate Facebook extraction programmatically
        

        
      

      

        
1. Extract Single Post

        
Send a POST request with the Facebook link:

        

          
curl -X POST "http://localhost:8000/api/extract" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://www.facebook.com/..."}'

        


        
2. Batch Extract Novel Series or Multiple Links

        

          
curl -X POST "http://localhost:8000/api/extract-batch" \
  -H "Content-Type: application/json" \
  -d '{"raw_text": "1.https://... 2.https://..."}'

        


        
3. Direct Media Proxy & Download

        
Bypasses Facebook CDN referer restrictions:

        

          
GET /api/proxy?url=<ENCODED_CDN_URL>
GET /api/download?url=<ENCODED_CDN_URL>&filename=photo.jpg
